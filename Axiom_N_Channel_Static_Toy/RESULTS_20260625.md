# D2 다중채널 정적식: 예측 토이모델 결과 노트

## 노트 분류

- 분류: `검증 노트 / 정적식 / Structural / D2 유한 토이모델`
- 대상: 공리-준수 다중채널 정적식
- 상태: 유한 구조 hold-out 검증 통과
- 비대상: 물리적 예측, 양자 현상, 입자 크기 상한, 경험적 검증

## 독립 목표량

각 admissible configuration \(p=(S,A)\)에서 모든 nonempty element-complete restriction을 직접 열거해, 기록된 활성 관계가 하나 이상 남는 비율을 계산했다.

\[
Y_{\mathrm{surv}}(p)
=
\frac{1}{2^{|S|}-1}
\sum_{\varnothing\ne Y\subseteq S}
\mathbf 1\!\left[A\cap R_Y\ne\varnothing\right].
\]

이 목표량은 \(D_1,D_2,D_3\)의 출력으로 정의하지 않았다.

## 단일 hold-out 결과

Carrier \(S\) 단위, \(|S|\) 층화 분할에서 전체 21,798개 비어 있지 않은 configuration 중 16,343개를 학습, 5,455개를 hold-out 평가에 사용했다.

```text
                         MAE        RMSE       R²
single-channel        0.054940519  0.072061009  0.814023758
fixed 3-channel       0.044879482  0.062630468  0.859515595
learned 3-channel     0.038376020  0.052241574  0.902256181
```

학습된 다중채널 비중은

\[
\boldsymbol{\theta}
=(0.664192924,\,0.266621493,\,0.069185583)
\]

이며, 단일채널 대비 MAE는 30.150%, RMSE는 27.504% 낮았다.

## 반복 분할 안정성

20개 seed에서 모든 경우 다중채널식의 MAE와 RMSE는 감소했고, \(R^2\)는 상승했다.

```text
MAE reduction mean ± std:  29.048% ± 3.344%
RMSE reduction mean ± std: 27.051% ± 1.655%
```

## 해석

이 결과는 세 채널이 이 D2 restriction-survival 목표를 단일 활성관계 채널보다 더 잘 근사한다는 유한 구조 수준의 근거다. 채널이 물리적 자유도이거나, 일반 물리 예측 정확도를 올린다는 결론은 아직 도출하지 않는다.
