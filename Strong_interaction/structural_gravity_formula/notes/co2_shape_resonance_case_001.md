# CO2 Shape-Resonance Case 001

## Purpose

Use the well-known electron-CO2 2Pi_u shape resonance as a transient-boundedness case in which structural change is genuinely multidimensional.

This is not a gravity measurement. It is a source-structure benchmark for deciding which variables should enter a later constitutive bridge.

## Empirical resonance anchor

Electron-CO2 scattering has a prominent shape resonance near

\[
E_r\approx 3.8\ \mathrm{eV}.
\]

A commonly quoted representative natural-width scale is

\[
\Gamma\approx 0.33\ \mathrm{eV},
\]

which gives

\[
\tau_\Gamma=\frac{\hbar}{\Gamma}
\approx1.995\times10^{-15}\ \mathrm{s}.
\]

The 0.33 eV width is retained as a literature/theory-scale value, not promoted to a direct experimental natural-width determination.

## Structural geometry

The neutral equilibrium CO bond length used in resonance studies is approximately

\[
r_{\rm CO}^{(0)}=2.1944\ a_0\approx1.16123\ \text{angstrom}.
\]

Along the linear symmetric-stretch path, calculations place an important resonance/anion crossing region near

\[
r_{\rm CO}\approx2.6\ a_0\approx1.37586\ \text{angstrom},
\]

which corresponds to a relative stretch

\[
\frac{2.6}{2.1944}-1\approx0.1848.
\]

A representative bent conical-intersection region occurs near

\[
r_{\rm CO}\approx2.4\ a_0\approx1.27003\ \text{angstrom},
\qquad
\angle OCO\approx130^\circ.
\]

This is roughly a 9.37% CO-bond stretch plus a large bending deformation from the linear neutral geometry.

## Consequence for the source-state variables

A single structural length is insufficient for this case.

Use a structural-coordinate vector, for example

\[
\mathbf L_{\rm struct}
=
(r_{\rm CO,1},r_{\rm CO,2},\theta_{\rm OCO},\ldots).
\]

For the symmetric subspace,

\[
\mathbf L_{\rm struct}^{\rm sym}
=
(r_{\rm CO},\theta_{\rm OCO}).
\]

The transient source state should therefore be written schematically as

\[
\mathcal S_{\rm tr}
=
(E_{\Sigma,\rm cm},\Delta E_{\rm tr},\Gamma,\tau,\mathbf L_{\rm struct},R_{\rm eff};\epsilon,\ldots).
\]

Do not equate the bond length or bend angle with a three-dimensional source radius.

## Resonance persistence diagnostic

For comparison only, define the dimensionless resonance ratio

\[
Q_r=\frac{E_r}{\Gamma}.
\]

For the representative CO2 resonance values,

\[
Q_r\approx11.52.
\]

This is a resonance-persistence diagnostic, not a DSD boundedness law.

## Current interpretation

CO2 shows that transient boundedness can reorganize geometry through more than one internal mode while keeping the constituent identity fixed.

The useful structural question is therefore not only

\[
\frac{\partial X}{\partial R_{\rm eff}},
\]

but more generally

\[
\left.
\frac{\partial X}{\partial L_a}
\right|_{E_{\Sigma,\rm cm}}
\]

for independently declared structural coordinates \(L_a\).

A later empirical gravity test would have to remove ordinary electromagnetic, scattering, finite-size, and multipole effects before attributing any residual to a new geometric response.
